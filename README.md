## Project

This project is a basic CPU design created for the Computer System Architecture (CSA) course.

### Features

- Register-based CPU architecture
- Addition
- Subtraction
- Multiplication
- Division
- Memory Read and Write
- Input and Output operations
- Program Counter (PC)
- Accumulator (AC)
- Address and Data Registers

### Microinstructions

- Register-to-register transfer
- Arithmetic operations
- Memory access
- PC increment
- Input/Output operations

### Purpose

This project demonstrates how a CPU performs data transfer, memory operations, and arithmetic operations using microinstructions.
